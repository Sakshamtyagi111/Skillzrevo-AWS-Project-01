Private S3. Global edge. Instant updates.

This page is served from a fully private S3 bucket through CloudFront (OAC), secured with an ACM certificate and routed by Route 53.

Build -

🔒 Private origin

Bucket blocks all public access. Only CloudFront can read it via Origin Access Control.

⚡ Smart caching

HTML is never cached. CSS, JS, fonts, images and videos are cached at the edge with long TTLs.

♻ Invalidation

Deploys and S3 events invalidate changed HTML/CSS/JS so updates show immediately.

🗂 Versioning

S3 versioning keeps every file revision for rollback; assets carry a content-hash version.
